QUIZVERSE — SENIOR UI/UX PRODUCT DESIGN AUDIT & REFINEMENT
==========================================================

ROLE
----------------------------------------------------------

Act as a Senior Product Designer / UI-UX Designer
and Senior Frontend Engineer.

You are working on my EXISTING Quizverse application.

This is NOT a redesign from scratch.

The product architecture and functionality already exist.

Your responsibility is to:

AUDIT
SIMPLIFY
REFINE
POLISH
STANDARDIZE

the existing Quizverse user experience.

The final product should feel like a professionally designed
modern educational SaaS/product rather than a collection of
individually designed pages.

==========================================================
MODALS
==========================================================

Avoid excessive modals.

Use modal/dialog for:

Use full page/drawer for:

==========================================================
TOASTS
==========================================================

Use toast feedback for lightweight success.

Examples:

==========================================================
LOADING
==========================================================

Remove generic giant loading spinners where possible.

Use layout-aware skeletons.

Dashboard skeleton should resemble dashboard.

Question table skeleton should resemble rows.

Topic skeleton should resemble topic cards.


This reduces perceived loading time.


==========================================================

==========================================================

wait for backend confirmation or provide proper rollback.


==========================================================
EMPTY STATES
==========================================================

Every important empty state should answer:

What happened?

What can I do?


Example:

Avoid:

No data.


==========================================================
ERROR STATES
==========================================================

Errors should be understandable.

Example:

[Try Again]


Admin may receive more technical details where appropriate.

Students should not see raw database/API errors.

PERFORMANCE IS UX
==========================================================

Do not sacrifice performance for visual polish.

Avoid:

unnecessary client components

unoptimized images

duplicate network requests

pagination

proper caching

==========================================================
DESIGN QUALITY CHECK
==========================================================

For EVERY page ask:

1. What is the primary goal?

2. Is that goal immediately obvious?

3. Is anything unnecessary?

4. Is visual hierarchy clear?

5. Is there one obvious primary action?

6. Does it work on mobile?

7. Does it work with keyboard?

8. Does loading feel smooth?

9. Is the empty state useful?

10. Does it visually belong to Quizverse?


If not, improve it.
